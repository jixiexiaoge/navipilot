## 二、详细端口分析

### 2.1 UDP 7705 — 车机状态广播（出站）

**协议**: UDP 明文 JSON
**方向**: 车机 → 局域网（广播）
**频率**: 约 20 Hz（Ratekeeper 节流）

**数据来源**: `make_send_message()` (cereal/openpilot)

**消息内容示例**:
```json
{
  "deviceIp": "192.168.x.x",
  "navi_points_active": true,
  "navi_points": [...],
  "speed": 60,
  "limitSpeed": 120
}
```

**用途**:
- 供局域网内设备发现车机
- App 端 `XiaogeDataReceiver` 接收设备状态
- 驾驶模式、车辆信息广播

---

### 2.2 UDP 7706 — 手机导航 JSON（入站）

**协议**: UDP JSON
**方向**: App → 车机
**处理**: `carrot_man_thread` → `json.loads` → `CarrotServ.update(json)`

**数据模型**: `CarrotManFields` (44字段)

**核心字段分类**:

| 类别 | 字段 | 说明 |
|------|------|------|
| 通信基础 | `carrotIndex`, `epochTime`, `carrotCmd` | 包序号、校时、命令 |
| GPS | `latitude`, `longitude`, `heading`, `gps_speed`, `accuracy` | 手机 GPS 位置 |
| 限速 | `nRoadLimitSpeed`, `roadcate` | 道路限速（带纠偏算法） |
| SDI 电子眼 | `nSdiType`, `nSdiSpeedLimit`, `nSdiDist` | 当前电子眼信息 |
| SDI Plus | `nSdiPlusType`, `nSdiPlusSpeedLimit`, `nSdiPlusDist` | 下一个电子眼信息 |
| TBT 转弯 | `nTBTDist`, `nTBTTurnType`, `szTBTMainText` | 转向引导信息 |
| 下一转向 | `nTBTNextRoadWidth`, `nTBTTurnTypeNext`, `szTBTMainTextNext` | 下一路口信息 |
| 目的地 | `goalPosX`, `goalPosY`, `szGoalName` | 导航目的地 |
| 当前位置 | `vpPosPointLat`, `vpPosPointLon`, `nPosAngle`, `nPosSpeed` | 车机融合 GPS |
| 路况 | `nGoPosDist`, `nGoPosTime`, `szPosRoadName` | 剩余路程/时间 |

**防抖机制**:
- `nRoadLimitSpeed` 需连续 6 帧相同才采纳（防抖动）
- 手机 GPS 覆盖车机 GPS 条件：navi 数据超过 3 秒未更新

**⚠️ Bug**: `szTBTMainTextNext` 代码实际读取的是 `szTBTMainText`（需修复）

### 2.3 TCP 7709 — 路线折线（二进制入站）

**协议**: TCP 二进制
**方向**: App → 车机
**处理**: `carrot_route` 线程

**数据格式**:
```
┌──────────────────┬─────────────────────────────────┐
│ 2字节 (LE16)     │ 点数量 N                         │
│ 4字节 (BE uint32)│ 后续 Payload 长度               │
│ N × 8字节        │ 每点: 经度(float32) + 纬度(float32) │
└──────────────────┴─────────────────────────────────┘
```

**用途**:
- 存储 `navi_points` 路线点
- 触发 `send_routes()` 发送到 openpilot
- 设置 `params["NavDestination"]`

**特点**:
- 不经过 `CarrotServ.update()`
- 直接维护 `navi_points` + `send_routes`
- 路线几何独立于 7706 的导航数据

---

### 2.4 ZMQ 7710 — 远程命令通道

**协议**: ZMQ
**方向**: App → 车机
**处理**: `carrot_cmd_zmq` 线程

**命令格式**: JSON 对象
```json
{
  "cmd": "shell|tmux|ftp|...",
  "arg": "命令参数"
}
```

**支持命令**:
| 命令 | 功能 |
|------|------|
| `shell` | 执行任意 shell 命令 |
| `tmux` | tmux 会话控制 |
| `ftp` | FTP 文件传输 |

**⚠️ 安全注意**: 可执行任意 shell 命令，需局域网隔离

---

### 2.5 TCP 7711 — 小哥数据广播（双向）

**协议**: TCP JSON
**方向**: 双向（车机 → App 为主）
**处理**: `XiaogeDataBroadcaster` 类

**车机 → App 数据**:
```json
{
  "carState": {...},
  "modelV2": {...},
  "controlsState": {...}
}
```

**App → 车机**:
- 仅发送 4 字节心跳: `uint32 = 2`

**重连策略**: 指数退避 2s → 5s → 10s → 20s → 30s max

**用途**:
- 实时车辆状态（速度、方向盘角度）
- openpilot 控制状态
- 驾驶模型输出

---

### 2.6 TCP 7712 — 行 JSON 分发

**协议**: TCP 明文（每行一个 JSON）
**方向**: App → 车机
**处理**: `carrot_navi_tcp_server` → `_dispatch_obj`

**支持的 JSON 顶层键**:

| 键 | 处理函数 | 说明 |
|----|---------|------|
| `rgdata` | `handle_carrot_state(d)` → `update(d)` | 导航数据（与 7706 语义相同） |
| `vrtx` | `handle_route(arr)` | 路线点数组（替代 7709） |
| `sinf` | `handle_traffic_light(d)` | 红绿灯信息 |
| `timestamp_ms` | `_is_stale_rgdata` | 去重时间戳 |

**`rgdata` 格式**（与 7706 相同）:
```json
{
  "rgdata": {
    "nRoadLimitSpeed": 120,
    "nSdiType": 1,
    "nTBTDist": 500,
    ...
  },
  "timestamp_ms": 1234567890
}
```

**`vrtx` 格式**:
```json
{
  "vrtx": [
    {"x": 116.397, "y": 39.908, "valid": true},
    {"x": 116.398, "y": 39.909}
  ]
}
```

**`sinf` 格式**（红绿灯）:
```json
{
  "sinf": {
    "redLightOn": true,
    "redLightRemainTime": 30,
    "distance": 50
  }
}
```

---

### 2.7 HTTP 7713 — 导航 API

**协议**: HTTP POST/GET
**方向**: App → 车机
**处理**: `carrot_http_post` → `_dispatch_obj`

**端点**:

| 路径 | 方法 | 功能 |
|------|------|------|
| `/navi` | POST | 接收 JSON 导航数据（同 7712） |
| `/health` | GET | 健康检查，返回 `{"status": "ok"}` |

**POST /navi 请求体**:
```json
{
  "rgdata": {...},
  "vrtx": [...],
  "sinf": {...}
}
```

---

### 2.8 UDP 12345 — KISA/Waze 文本协议

**协议**: UDP 文本（键值对）
**方向**: App → 车机
**格式**: `key:value/key:value`

**处理函数**: `parse_kisa_data` → `update_kisa`

**支持的键**:
| 键 | 用途 |
|----|------|
| `kisawazeroadspdlimit` | 道路限速 → `xSpdLimit` |
| `kisawazeroadname` | 道路名称显示 |
| `kisawazereportid` | 报告 ID |
| `kisawazealertdist` | 报警距离 → `xSpdType` |

**特点**:
- 不经过 `update()`，走独立 `update_kisa()`
- 影响 `xSpd*` 字段（独立于主导航数据）
- CPlink App 通常不使用此端口

## 四、协议对比

| 特性 | 7706 UDP | 7712 TCP | 7713 HTTP | 7709 TCP |
|------|----------|----------|------------|----------|
| 格式 | JSON | 行 JSON | JSON POST | 二进制 |
| 路线 | ❌ | `vrtx` 数组 | `vrtx` 数组 | 二进制点 |
| 导航数据 | ✅ | `rgdata` | `rgdata` | ❌ |
| 红绿灯 | ❌ | `sinf` | `sinf` | ❌ |
| 可靠性 | 无确认 | TCP 可靠 | HTTP可靠 | TCP 可靠 |
| 频率 | 5-20Hz | 随时 | 随时 | 规划时 |

---

## 五、安全注意事项

1. **所有端口默认绑定 `0.0.0.0`**，无认证/TLS，仅限局域网
2. **ZMQ 7710** 可执行任意 shell 命令，必须网络隔离
3. **HTTP 7713** 可覆盖导航状态，生产环境应限制来源 IP
4. **WebSocket** 暴露 cereal 消息，含车辆控制数据

## 六、快速参考

### 发送导航数据的最小字段集

```json
{
  "carrotIndex": 1,
  "nRoadLimitSpeed": 120,
  "nTBTDist": 500,
  "nTBTTurnType": 12,
  "szTBTMainText": "前方500米右转",
  "vpPosPointLat": 39.908,
  "vpPosPointLon": 116.397,
  "nPosAngle": 45.0,
  "nPosSpeed": 60.0
}
```

### 发送路线点（二进制）

```python
import struct
points = [(116.397, 39.908), (116.398, 39.909)]
data = struct.pack('!H', len(points))  # 点数量
data += struct.pack('!I', len(points) * 8)  # payload长度
for lon, lat in points:
    data += struct.pack('!ff', lon, lat)  # 经度、纬度
```
