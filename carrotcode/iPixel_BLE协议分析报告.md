# iPixel Color BLE 协议逆向分析报告

基于 HCI 抓包数据逆向分析 + 实机验证（2026-02-24）。

---

## 1. 硬件信息

- 设备: iPixel Color LED 点阵屏
- 屏幕: 16×64 像素（16高 × 64宽），每像素 RGB 三色 LED
- BLE 设备名: `LED_BLE_XXXXXXXX`
- 支持: 中文、英文、数字、图片、颜色调整、动画特效

---

## 2. BLE 连接信息

### GATT 服务结构

| Service UUID | 说明 |
|---|---|
| `0x1800` | Generic Access（标准 GAP 服务） |
| `0x00FA` | **iPixel 主数据服务** |
| `0xAE00` | 辅助服务（固件更新/配置） |

### 主数据服务 `0x00FA`

| Characteristic UUID | 属性 | 用途 |
|---|---|---|
| `0xFA02` | WRITE_NO_RESP, WRITE | **App → LED屏 发送数据** |
| `0xFA03` | NOTIFY | **LED屏 → App 回复/状态** |

### 连接参数
- MTU: 512
- Write 类型: WRITE_TYPE_NO_RESPONSE (opcode 0x52)
- 连接后需启用 0xFA03 的 Notification (写 CCCD `01 00`)

## 3. 协议格式

### 3.1 控制命令（短包）

```
格式: [总长度 LE16] [命令码 LE16] [参数...]
```

| 命令 | 包数据 | 含义 |
|---|---|---|
| 握手 | `08 00 01 80 15 01 16 01` | 连接后第一个命令 |
| 查询设备 | `04 00 05 80` | 查询设备信息 |
| 选择页面 | `07 00 08 80 01 00 XX` | XX=页码(01-05, 65=预览) |
| 清屏 | `04 00 03 80` | 清除屏幕内容 |

### 设备回复（Notification）

| 回复数据 | 含义 |
|---|---|
| `0b 00 01 80 83 01 ...` | 握手确认 |
| `08 00 05 80 0e 11 01 04` | 设备信息 |
| `05 00 08 80 01` | 页面选择确认 |
| `05 00 00 01 03` | 数据帧接收确认 |
| `05 00 03 80 01` | 清屏确认 |

### 3.2 数据帧格式（文字/图片）

29 字节帧头 + N 个字符块：

```
偏移  长度  字段              说明
──────────────────────────────────────────
0     2    total_len         整包总长度 (LE16)
2     2    frame_type        固定 0x0001
4     1    zero              固定 0x00
5     2    payload_len       有效载荷长度 (LE16) = total_len - 15
7     1    zero              固定 0x00
8     5    content_hash      CRC32(frame[15..end]) LE32, byte[8]固定0x00
13    1    zero              固定 0x00
14    1    page              页面编号 (0x65=预览模式)
15    1    char_count        字符数量
16    1    zero              固定 0x00
17    1    one               固定 0x01
18    1    one               固定 0x01
19    1    animation         动画效果代码
20    1    marker_P          固定 0x50 ('P')
21    1    color_mode        0x00=默认白, 0x01=自定义颜色
22    3    fg_rgb            前景色 RGB
25    4    bg                背景 (通常全0)
```

### 3.3 字符块格式

iPixel 使用两种字符块格式：

#### marker=0x80 块（38字节）— 字母和汉字

```
偏移  长度  字段
0     1    marker = 0x80
1     3    RGB 前景色
4     1    width (像素宽度)
5     1    height (固定16)
6     32   bitmap (列优先, 16列×2字节)
```

适用于: 大写字母、小写字母、汉字等所有字符。

#### marker=0x00 块（20字节）— 数字（iPixel原生App使用）

```
偏移  长度  字段
0     1    marker = 0x00
1     3    RGB 前景色
4     16   bitmap (8×16 行优先)
```

> 我们的实现统一使用 0x80 格式，对所有字符都有效。

### 3.4 位图编码

列优先格式 (column-major), LSB = row 0:
- 每列 2 字节: byte[0] = row 0-7 (bit0=row0), byte[1] = row 8-15
- 16 列 × 2 字节 = 固定 32 字节
- 字符宽度由 width 字段指定，屏幕只显示 width 列

**关键: 字符需要预旋转**

iPixel 屏幕显示的字符是"横躺"的。Canvas 渲染正常竖直字符后，需要做转置变换才能正确显示：

```
变换公式: rotated[row][col] = original[col][row]
```

即: 矩阵转置（等价于沿主对角线翻转）。字符块按正常左到右顺序排列。

## 4. 动画效果代码

帧头 byte[19] 控制动画：

| 代码 | 效果 |
|---|---|
| 0x00 | 静态显示 |
| 0x01 | 向左滚动 |
| 0x02 | 向右滚动 |
| 0x06 | 呼吸闪烁 |
| 0x08 | 激光效果 |

## 5. 通信流程

```
App                              LED屏
 |                                 |
 |-- 握手 (0x8001) --------------->|
 |<-- 握手确认 --------------------|
 |                                 |
 |-- 查询设备 (0x8005) ----------->|
 |<-- 设备信息 --------------------|
 |                                 |
 |-- 选择页面 (0x8008) ----------->|
 |<-- 页面确认 --------------------|
 |                                 |
 |-- 清屏 (0x8003) [可选] -------->|
 |<-- 清屏确认 --------------------|
 |                                 |
 |-- 数据帧 (帧头+字符块) -------->|
 |<-- 接收确认 (03) ---------------|
```

### 发送文字的完整步骤

1. 连接 → 请求 MTU 512 → 发现服务 0x00FA
2. 启用 0xFA03 Notification
3. 发送握手 → 等待确认
4. 查询设备信息
5. 清屏（避免重复发送不更新）
6. 选择页面 (0x65 = 预览模式)
7. 构建数据帧: 帧头 29B + 字符块(正常顺序) → 发送
8. 等待接收确认

## 6. 实现说明 (LedMatrixManager.kt)

### 字符渲染流程

1. Android Canvas 渲染字符为 16×16 位图（正常竖直方向）
2. 提取二值像素矩阵
3. 应用转置变换: `rotated[r][c] = original[c][r]`
4. 转为列优先位图 (32 字节)
5. 字符块按正常顺序组装帧

### 颜色支持

- `color_mode = 0x00`: 默认白色
- `color_mode = 0x01`: 自定义 RGB，每个字符块独立指定颜色

### 屏幕容量

- 屏幕宽 64 像素
- 英文/数字: 约 8-14px 宽，可显示 ~5-7 个字符
- 汉字: 16px 宽，可显示 4 个字符
- 超出部分使用滚动动画显示
