🗺️ NAVIGATION

三模导航，无缝切换

OSM / 高德 / 腾讯三种导航引擎互斥运行，同一时刻只有一种模式写入数据，自动切换、零手动干预。

🔵 OSM 模式 默认

基于 OpenStreetMap + OSRM/腾讯混合路由，完全免费、全球可用。MapLibre 卫星地图渲染，支持搜索、路线规划、TBT 转弯引导。

🟢 高德模式 自动

检测到高德地图车机版广播时自动激活，获取实时路况、电子眼、限速、车道线等完整导航数据。导航结束 30 秒后自动回退。

🟣 腾讯模式 SDK

集成腾讯导航 SDK v7.5.0，3D 实景导航、TTS 语音播报、区间测速、道路吸附坐标。进入腾讯导航页面时自动切换。

📡 POSITIONING

厘米级高精度定位

多级 GNSS 增强定位引擎，从 RTK 固定解到 SBAS 双频，自动选择最优定位模式。

🎯

NTRIP CORS 差分

连接六分科技 / 千寻位置等 CORS 服务，获取 RTCM3 差分数据流，实现 DGNSS（1-2m）到 RTK 固定解（厘米级）。

📶

双频 GNSS 解算

从 Android Raw GNSS API 提取 L1+L5 伪距，无电离层组合消除延迟，加权最小二乘法解算。支持 GPS / GLONASS / Galileo / BDS 四系统。

🔄

卡尔曼滤波融合

GPS + IMU 3D 状态向量融合，精度自适应增益、静止防漂移、航向校准、大误差硬重置。移植自 Dashy gpsd.py。

🤖 INTELLIGENCE

AI 驾驶辅助

实时视频流 + ML Kit 车辆检测 + 多维超车决策，为 OpenPilot 提供更丰富的环境感知。

🎥

WebRTC 实时视频

通过 WebRTC 连接 Comma3 前置摄像头，圆角悬浮窗实时显示路况画面，支持折叠/展开。

👁️

车道车辆检测

ML Kit Object Detection 实时分析视频帧，画面三等分识别左右车道车辆，边缘红色渐变警告条提示盲区风险。

🚗

智能超车决策

综合前车距离、速度差、车道线曲率、方向盘角度、TBT 转向偏好等多维数据，支持禁止超车 / 拨杆超车 / 自动超车三种模式。

🛣️

车道级导航

基于高精度定位检测当前车道，结合导航指令推荐正确车道，生成车道变更引导（方向 + 紧急程度）。

⚡ PROTOCOL

实时数据通道

📊 DATA FIELDS

UDP 7706 核心字段

三种模式统一写入 CarrotManFields，通过 convertCarrotFieldsToJson() 序列化后发送。以下为关键字段覆盖情况。

📍 GPS 位置（9 字段）

latitude / longitude / heading / accuracy / gps_speed — 三模均来自手机 GPS。vpPosPointLat/Lon — OSM 用 GPS，高德用 GCJ-02 广播坐标，腾讯用 SDK 道路吸附坐标（最精确）。

🔀 TBT 转弯引导（9 字段）

nTBTDist / nTBTTurnType / szTBTMainText — 距下一转弯距离、类型编码、指令文本。支持双层 TBT（下一转弯 + 下下转弯），三模均完整覆盖。

📷 SDI 电子眼（15 字段）

nSdiType / nSdiSpeedLimit / nSdiDist — 电子眼类型、限速、距离。支持双电子眼 + 区间测速。高德和腾讯完整覆盖，OSM 模式无电子眼数据。

🛣️ 道路信息（4 字段）

szPosRoadName / nRoadLimitSpeed / roadcate / nLaneCount — 当前道路名、限速、道路类别（高速/快速/普通）、车道数。腾讯模式通过 NavRoadType + grade/kind 精确推断。

🚀 QUICK START

快速上手

1

安装 APK

下载最新版 NaviPilot APK 安装到手机，授予定位、通知等权限。

2

连接 Comma3

确保手机与 Comma3 在同一局域网（热点或 Wi-Fi），App 自动发现设备并建立 UDP 连接。

3

开始导航

OSM 模式：搜索目的地 → 点击导航。高德模式：打开高德车机版自动切换。腾讯模式：底部导航栏进入。
